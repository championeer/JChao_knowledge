【AI 中转站实测分享】

最近用 Claude 比较多，但官方太肉疼了，试了几家中转站，分享一下真实体验。

目前稳定两家，再加一个备选。

1⃣ AI 奶爸 @zstmfhy（主力）

链接：http://manage-xai.ainaibahub.com

用了一段时间，最大的感受是稳。前两天他们升级 cache 策略翻车了，用户端费用直接飙升，

换别家可能先冷处理，但第一条推就是认锅，查清楚原因，直接返还 50% 到 100%，技术会出问题我能理解，出了问题怎么处理才见人品。

2⃣ 三海 DAPI @10UWINA8（在试）

链接：http://dapicloud.com/register?aff=9rwZ…

今天刚注册，三海是潜水（ @connectfarm1 ）的助理，圈内老人了。汇率 1:1，成本低至官方 1.3 到 2 折。

用的时候发现深色模式下用户名字体有点看不清，顺手反馈了一句，没想到回得特别快。一个站靠不靠谱，看大事故怎么处理是一方面，看小毛病响应多快也能感觉出来。继续用着看。

3⃣ TokenNav 中转站导航（备选）

链接：http://tokennav.cc

中转站导航，收录了 47 家，可以按模型、支付方式、价格筛选。还没深度用，先当工具收藏了。

现在大概就是奶爸保底，三海测试，TokenNav 找新站的时候翻一翻。大家有在用的靠谱站也丢评论区。
